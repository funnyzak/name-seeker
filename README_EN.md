NameSeeker is a powerful cross-platform desktop application that searches for usernames and email addresses across hundreds of websites, helping you quickly discover your digital footprint. Based on the WhatsMyName project data, it supports exporting search results in PDF, CSV, JSON, and other formats.

## Key Features

- **Comprehensive Search**: Search usernames and email addresses across 600+ websites
- **Real-time Progress**: Live display of search progress and results
- **Multiple Export Formats**: Support for CSV, JSON, PDF, TXT, and other export formats
- **Smart Filtering**: Advanced filtering and sorting options
- **Search History**: Search history records for quick access
- **Privacy Protection**: Local processing - no data sent to external servers
- **Multi-language Support**: Support for Chinese and English languages
- **Cross-platform**: Support for Windows, macOS, and Linux

## Data Source

This application is based on the data source from the [**WhatsMyName**](https://github.com/WebBreacher/WhatsMyName) project, which maintains search rules for 600+ websites. WhatsMyName is an open-source project that provides JSON files needed for username enumeration, widely used by numerous OSINT tools and websites.

## Special Thanks

Thanks to the inspiration and reference from the [**Blackbird**](https://github.com/p1ngul1n0/blackbird) project. Blackbird is a powerful OSINT tool that supports searching usernames and email addresses across 600+ platforms, with integrated free AI analysis capabilities that can generate user behavior and technical profiles.

## Privacy and Security

- **Local Processing**: All searches are executed locally without uploading data to external servers
- **No Tracking**: No collection of user data or analytics information
- **Open Source Transparency**: Fully open source with auditable code
