# NameSeeker

NameSeeker is a powerful username search tool inspired by OSINT tools. It provides a user-friendly graphical interface for discovering public profiles based on usernames, designed for educational and ethical self-research purposes.

## Development

```bash
# Frontend-only development
npm run dev

# Full application development
npm run tauri dev

# Code Quality Tools
npm run type-check      # TypeScript type checking
npm run lint            # ESLint code linting
npm run lint:fix         # Auto-fix ESLint issues
npm run format           # Prettier code formatting
npm run format:check     # Check code formatting
npm run ci               # Run all quality checks

# Build for production
npm run tauri build
```

## Privacy & Security

- **Local Processing**: All searches are performed locally, no data is sent to external servers
- **No Tracking**: No user data or analytics information is collected
- **Open Source Transparency**: Fully open source with auditable code
